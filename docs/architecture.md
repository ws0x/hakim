# Architecture: Hakim (حَكِيم)

## Overview

Hakim is composed of two primary runtime applications and several shared domain packages:

```text
┌─────────────────────────────────────────────────────────────┐
│ Chromium Browser (User Authenticated Session)                │
│  └── apps/extension (Manifest V3)                           │
│        • Background Worker (Alarms, Network Fetcher)        │
│        • Regional Amazon Matcher (.com, .co.uk, .de, etc.)  │
│        • Chunked Pagination & Checkpointing                 │
│        • Popup UI & Health Status                           │
└──────────────────────────────┬──────────────────────────────┘
                               │ Paired HTTP (Token Auth)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ Hakim Local Engine (127.0.0.1:port)                          │
│  ├── Fastify REST API                                       │
│  ├── Ingestion & Parser Adapters (Cloud, Clippings, HTML)   │
│  ├── Deduplication & Normalization Service                  │
│  ├── SQLite Authoritative Database (WAL Mode)               │
│  ├── Notion Sync Worker (Paced 3 req/s, Retry-After)        │
│  ├── Obsidian / Markdown Vault Exporter                    │
│  └── Reading Intelligence Pipeline (Provider Agnostic LLM) │
└──────────────────────┬──────────────────────────────┬───────┘
                       │                              │
                       ▼                              ▼
          ┌─────────────────────────┐   ┌─────────────────────────┐
          │ Notion Workspace        │   │ Local Filesystem        │
          │ (7 Relational DBs)      │   │ (Obsidian Vault .md)    │
          └─────────────────────────┘   └─────────────────────────┘
```

## Architectural Invariants

1. **Authoritative Local Store**: SQLite is the single source of truth for all books, annotations, user state, and sync logs.
2. **Loopback Isolation**: The engine binds strictly to `127.0.0.1`. Remote access is prohibited without explicit proxy/auth design.
3. **Paired Communication**: Extension requests must include a high-entropy pairing token generated by the engine.
4. **Controlled Bidirectional Projection**: Notion is a projection of the local database. User edits are pulled before source updates are pushed.
5. **No Credential Exfiltration**: The extension queries `read.amazon.com/notebook` using the browser's ambient cookie jar. Passwords and cookies are never serialized or transmitted.
6. **Graceful Degradation**: If the local engine is offline, the extension buffers parsed import envelopes in `chrome.storage.local` until reconnected.
